# Event 06: CelesteJam / CosmoJam (CJam)
**Discipline:** Aerospace Game Development & Interactive Media  
**Eligibility:** Junior (Grades 6–8) · Senior (Grades 9–12) — Judged Separately  
**Team Composition:** 2–3 members (Same school delegation)  
**School Limit:** Max 1 team per category (Junior / Senior)  
**Competition Mode:** Onsite (Remote Theme Build Phase → Onsite Peer Playtesting & Jury Defense)  
**Official Motto:** *"You can discover more about a person in an hour of play than in a year of conversation." — Plato*

---

## 1. Executive Summary
CelesteJam (CosmoJam) is a rapid-fire game jam fusing software architecture with aerospace mechanics and game design aesthetics. Teams build a playable, polished minigame around an assigned secret theme using any game development engine. On conclave day, laptops turn into arcade booths for interactive peer review, playtesting telemetry, and algorithmic jury defense.

---

## 2. Round Structure & Deliverables

### Phase 1: Theme Release & Remote Build Sprint
- **Theme Announcement:** 10 October 2026, 00:00:00 IST on portal
- **Development Window:** 10 October – 22 October 2026
- **Engines Permitted:** Godot, Unity, Unreal Engine, WebGL (Three.js / Phaser), Pygame, GameMaker, or custom C++/Rust engines. All code written must be original.
- **Upload Deliverable:**
  1. Standalone Executable (Windows 64-bit `.zip`) OR Hosted WebGL link (itch.io / GitHub Pages).
  2. 60–90 second Gameplay Traversal Video highlighting mechanics, audio design, and UI.
  3. Source code repository link (GitHub / GitLab) or packaged scripts for code integrity review.

### Phase 2: Onsite Playtest Arcade & Jury Defense
- **Date & Reporting:** 24 October 2026, 07:45 AM at Welcome Foyer, DPS R.K. Puram
- **Setup:** Bring laptops running the playable build, controllers (optional), and headphones.
- **Arcade Floor:** Teams host playtesting stations where fellow competitors play and rate the game.
- **Jury Code Walkthrough:** Judges inspect physics simulation routines, shader optimizations, asset pipelines, and player progression mechanics.

---

## 3. Evaluation Criteria (100 Points Total)
- **Gameplay Mechanics & Fun Factor (25 pts):** Fluid controls, responsive physics (gravity, thrust, inertia), and engaging game loop.
- **Theme Interpretation & Narrative Polish (20 pts):** Creative implementation of the secret conclave prompt.
- **Visual Aesthetic & Audio Atmosphere (20 pts):** Art style consistency, visual feedback, particles, and custom sound design.
- **Technical Architecture & Optimization (20 pts):** Stable 60 FPS performance, clean object-oriented or ECS code, and bug-free execution.
- **Peer Playtest Reception & Jury Defense (15 pts):** Player feedback telemetry and clear explanation of design decisions.
